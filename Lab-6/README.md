Experiment 6: Continuous Integration Using GitHub Actions



OBJECTIVE

To implement Continuous Integration using GitHub Actions.



DESCRIPTION

GitHub Actions automates workflow execution when code is pushed to GitHub or a pull request is created.



ACTIVITIES PERFORMED

1\. Created a GitHub Actions workflow.

2\. Configured push and pull request triggers.

3\. Added a build job using Ubuntu.

4\. Used actions/checkout to access repository code.

5\. Executed a success message through the workflow.

6\. Pushed the workflow to GitHub.

7\. Verified successful execution in GitHub Actions.



TOOLS USED

\- Git

\- GitHub

\- GitHub Actions

\- YAML

\- Command Prompt



RESULT

The CI workflow executed successfully on GitHub Actions.
